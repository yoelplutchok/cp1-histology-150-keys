# CP1 Histology: the 150 key questions

150 multiple-choice questions, one per key fact, chosen by working through all 747 practice questions on the CP1
histology question page (learning questions excluded; the partly-CP1 "Borderline" questions counted at low weight) and
the two 2026 CP1 histology TA reviews (Harlem and Great Falls), keeping the facts that answer the most of them, directly
or by elimination. Covers the heart, vessels and lymphatics, the circulatory lab, the respiratory lecture and the
respiratory lab. Each question has a Key fact box (with recognition features for micrograph questions), a "What it
unlocks" dropdown (how the fact is tested, what it eliminates, links to the straight-recall questions), a Slides
dropdown (lecture, lab and TA slides; tap to enlarge), and a "Questions it helps you answer" dropdown with the
non-obvious practice and TA questions, answerable in place.

Live page: https://yoelplutchok.github.io/cp1-histology-150-keys/

*_hidden.json, *_add.json → patch.py → build.py).
